# Machine Learning Exercises

This repository contains a small collection of Jupyter notebooks that I created for practical sessions in an introductory machine learning course.

The notebooks were designed as simple teaching examples to complement the course lectures and help students explore fundamental machine learning concepts through Python implementations and experiments.

## Exercises

1. **Introduction and Perceptron Learning**  
   Basic machine learning concepts and the perceptron learning algorithm.

2. **Linear Regression**  
   An introduction to modeling continuous relationships with linear regression.

3. **Logistic Regression**  
   Binary classification using logistic regression.

4. **Evaluation Metrics**  
   Examples of metrics used to evaluate machine learning models.

5. **Multilayer Perceptron**  
   An introductory example of a feed-forward neural network.

## Purpose

These notebooks document part of my teaching experience and the practical material I prepared for students. They are intentionally small and introductory rather than a complete machine learning course or a production-ready software project.
